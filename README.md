# Paycheck Splitter

A simple phone app that takes the hours I worked, figures out my take-home pay, and splits it into Spend, Save, and Goal money. It also tracks how close I am to my savings goal.

Built with HTML, CSS, and JavaScript as my first coding project.

**Use it:** open the GitHub Pages link on your phone and tap Share → Add to Home Screen.
